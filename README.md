# Dynamic Poll Engine — SPA-система динамических опросов

Веб-приложение для создания и прохождения интерактивных опросов и тестирований со сложной логикой динамического ветвления вопросов.

🔗 **[Посмотреть Live Demo](https://raytwitty.github.io/dynamic-poll-engine/)**

Модернизированная версия реального продакшн-модуля опросов (ранее внедренного на портале https://narod-expert.ru/), переписанная с нуля с legacy-стека (Class Components / Redux) на современный React, TypeScript и Redux Toolkit.

---

## 📋 Ключевая функциональность

- **Динамическое ветвление сценария:** Поддержка зависимых вопросов (`related_answer_id`), которые автоматически добавляются в очередь прохождения или удаляются при изменении предыдущих ответов.
- **Гибкая настройка вариантов ответа:** Одиночный выбор (`radio`), множественный выбор (`checkbox` с ограничением максимального количества вариантов), свободный текстовый ввод («Свой вариант» с валидацией) и поддержка медиаконтента.
- **Умный расчет прогресса:** Динамический пересчет шкалы выполнения опроса в реальном времени с учетом открытых и закрытых веток вопросов.
- **Режим просмотра результатов и статистики:** После завершения опроса или при загрузке пройденной анкеты с сервера интерфейс переходит в режим чтения с отображением процентного соотношения голосов и скачиванием итогового отчета.
- **Автономный режим разработки (Mock API):** Встроенный слой имитации сетевых запросов с задержками и локальными JSON-данными, переключаемый через переменные окружения.

## 🏗 Архитектура и инженерные решения

Проект построен по модульному принципу с четким разделением ответственности между слоем данных, бизнес-логикой и представлением:

```text
src/
├── app/          # Конфигурация Redux store и изолированный API-слой с поддержкой моков
├── types/        # Контракты данных от API и типы UI-компонентов
├── slices/       # Redux Toolkit слайсы (управление опросом, очередью вопросов и роутингом)
├── hooks/        # Кастомные хуки с инкапсуляцией сложной бизнес-логики (useQuestionsScreen)
├── components/   # UI-компоненты и экраны приложения
└── shared/       # Переиспользуемые чистые утилиты (форматирование дат, склонение числительных)
```

### Оптимизации производительности:

1. **Алгоритмическая сложность $O(1)$:** Поиск связей между выбранными ответами и зависимыми вопросами, а также фильтрация дубликатов в очереди реализованы через структуры данных `Set` и `Map` вместо вложенных циклов.
2. **Мемоизация вычислений:** Расчет динамического прогресс-бара обернут в `useMemo` для исключения лишних пересчетов при ререндерах.
3. **Декомпозиция UI и логики:** Вся логика навигации, валидации и перестроения очереди вынесена в кастомный хук `useQuestionsScreen`, оставляя компоненты максимально декларативными.

## 🚀 Локальный запуск

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/RayTwitty/dynamic-poll-engine.git
   ```

2. **Установите зависимости:**

   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта (по умолчанию можно включить режим моков для работы без бэкенда):

   ```env
   VITE_USE_MOCKS=true
   VITE_API_URL=http://localhost:8000
   ```

4. **Запустите сервер для разработки:**

   ```bash
   npm run dev
   ```

   Приложение будет доступно по адресу: `http://localhost:5173/dynamic-poll-engine/`

5. **Запустите юнит-тесты:**
   ```bash
   npm test
   ```
